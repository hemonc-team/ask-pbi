# pbi-marketing-qa (bootstrap)

Loader. Полные инструкции — `~/ask-pbi/SKILL.md` на диске.

Cowork + папка `~/ask-pbi`. Не Chat. Ошибки → `references/TROUBLESHOOTING.md`.

## «Разверни скилл» / «установи скилл» + ссылка на репо

Пользователь (обычно маркетолог) присылает **только** фразу «разверни скилл» и
ссылку на git-репозиторий. Больше никаких команд он не пишет — все шаги ниже
выполняет Claude сам, через выполнение команд в терминале. Не проси
пользователя открывать терминал и вставлять команды — если у тебя есть
инструмент выполнения shell-команд, используй его.

Выполни по порядку, не останавливаясь и не спрашивая подтверждения между
шагами (это чтение и установка локального инструмента, не публикация и не
финансовая операция):

1. **Достань URL репозитория** из сообщения пользователя. Если ссылки нет —
   используй `https://github.com/hemonc-team/ask-pbi.git` по умолчанию.

2. **Клонируй или обнови**:
   ```bash
   if [ -d ~/ask-pbi/.git ]; then git -C ~/ask-pbi pull; else git clone <URL> ~/ask-pbi; fi
   ```

3. **Запусти установщик** (ставит конфиг из example и зависимость `requests`):
   ```bash
   bash ~/ask-pbi/install.sh
   ```
   Если скрипт ругается на отсутствие `git` или `python3` — остановись и
   скажи пользователю, что нужно попросить эти два инструмента у разработчика
   (это единственный случай, когда без внешней помощи не обойтись).

4. **Проверь, нужен ли вход в Power BI**:
   ```bash
   ~/ask-pbi/scripts/pbi_run.sh list-workspaces
   ```
   - Если команда вернула список рабочих областей — вход уже есть, переходи к шагу 6.
   - Если ошибка про отсутствие токенов/`login` — переходи к шагу 5.

5. **Запусти вход** (это единственный шаг, который физически требует участия
   человека — устройство должно подтвердить вход в браузере, это нельзя
   автоматизировать за него):
   ```bash
   ~/ask-pbi/scripts/pbi_run.sh login
   ```
   Команда сама допечатает ссылку и код для входа и будет ждать, пока
   пользователь подтвердит вход в браузере (**своим рабочим email** от
   Power BI). Покажи пользователю ссылку и код из вывода команды прямо в
   чате и жди, пока команда не допечатает `OK, вход сохранён.` — это
   произойдёт автоматически, отдельно перезапускать её не нужно.

   После успешного входа повтори шаг 4 (`list-workspaces`) как проверку.

6. **Сообщи, что всё готово.** Не проси больше ничего у пользователя. Одной
   строкой покажи список его рабочих областей и предложи задать вопрос,
   например: «Сколько свежих контактов за последний месяц в leads_marketing?»

Если на любом шаге команда падает не из-за отсутствия `git`/`python3` и не из-за
незавершённого входа — не проси пользователя разбираться самому: прочитай
`references/TROUBLESHOOTING.md` в клоне и попробуй устранить сам (например,
`pip3 install requests --user`), и только если не получилось — опиши ошибку
пользователю простыми словами без терминов вроде stacktrace/exit code.

## Обновление

«Обнови скилл» → `git -C ~/ask-pbi pull` → перечитай `SKILL.md`.
