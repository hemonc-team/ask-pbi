# pbi-marketing-qa (bootstrap)

Тонкий loader. Полные инструкции — в git-клоне на диске пользователя.

## Перед любым вопросом про Power BI / дашборд / метрики / лиды

1. Прочитай файл `~/ask-pbi/SKILL.md` **на диске пользователя**.
2. Скрипты только: `~/ask-pbi/scripts/pbi_run.sh` — и только если команда реально выполняется на компьютере пользователя (есть интернет до Power BI и файл `~/.pbi/tokens.json`).

## Если нет доступа к `~/ask-pbi` или к терминалу

Это режим **Chat** или облако: файлов и скриптов на компьютере не видно. **Не** предлагай `marketing-analysis`, `powerbi-modeling-mcp`, XMLA, репозиторий content-fabric и не выдумывай цифры.

Скажи коротко: откройте **Cowork** (не Chat), выберите **на этом компьютере**, разрешите папку `ask-pbi`, задайте вопрос снова.

Если папки `~/ask-pbi` правда нет на диске — `install.sh`, см. `references/SETUP_MARKETER.md`. Если пользователь уже ставил — не просите ставить заново.

## Обновление

Если пользователь просит **обновить skill** / **обнови скилл**:

```bash
git -C ~/ask-pbi pull
```

Затем перечитай `SKILL.md` из обновлённого пути.

## Ограничение

Этот bootstrap меняется редко. Не дублируй сюда бизнес-логику — она только в git `SKILL.md`.
