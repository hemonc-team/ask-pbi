# Частые меры (шпаргалка)

Имена на русском/английском — уточняй через `discover-schema`, если мера не найдена.

## leads_marketing

| Мера (пример) | Тема |
|---|---|
| `Количество свежих контактов` | свежие лиды |
| `Fresh_Contact_Conversion_Rate_%` | конверсия fresh contact |
| `Количество лидов` | лиды Calltouch/CRM |

## KPI marketing view

| Мера (пример) | Тема |
|---|---|
| `Посетители` / меры с «Посетител» | трафик Метрики |
| `Количество лидов` | лиды DWH |

Для «за период» используй `CALCULATE` / `DATESINPERIOD` / фильтр по таблице дат — не выдумывай числа без DAX.
