# Вопросы к дашбордам через Claude

Claude на вашем компьютере отвечает по цифрам из Power BI обычным языком — лиды,
KPI, конверсия, посетители сайта. Отчёты вручную открывать не нужно.

Claude **только читает** данные и не меняет отчёты.

---

## Что нужно

- Подписка Claude (Pro или Team)
- **Ключ доступа** — пришлёт Михаил (один раз, в личку)
- Доступ к отчётам в [app.powerbi.com](https://app.powerbi.com), как раньше

Ничего дополнительно ставить не нужно: ни Python, ни git.

---

## Настройка один раз

### 1. Установить Claude Code

**Mac** — откройте «Терминал» и вставьте:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Закройте терминал и откройте заново. Проверка:

```bash
claude --version
```

Если пишет `command not found: claude`:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
claude --version
```

**Windows** — PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Потом новое окно PowerShell и `claude --version`.

Первый раз запустите `claude` — откроется браузер, войдите рабочим email.

### 2. Подключить дашборды

Михаил пришлёт **ключ** (длинная строка). Подставьте его вместо `ВАШ_КЛЮЧ`:

```bash
claude mcp add --transport http --scope user ask-pbi https://pbi.hemonc.ru/mcp \
  --header "Authorization: Bearer ВАШ_КЛЮЧ"
```

Проверка:

```bash
claude mcp list
```

Строка `ask-pbi` должна быть с галочкой **Connected**. Если ошибка — напишите Михаилу.

## Каждый день

В любой папке: `claude` → спросите, как коллегу:

- «Сколько всего свежих контактов сейчас?»
- «Сколько свежих контактов было в июне?»
- «Как изменилась посещаемость сайта в 2026 по сравнению с 2025?»

Можно без слов «Power BI» и «дашборд».

**Сейчас работает:** свежие контакты, конверсия свежих контактов, конверсия
записи в приём, посетители и просмотры сайта. Список будет расти.

**Важно:** конверсию свежих контактов спрашивайте **за один месяц** (например
«в июне» или «май против апреля»). За квартал целиком по этой цифре Claude
скажет, что так нельзя — это ограничение самой модели, не Claude.

Обновлять ничего на компьютере не нужно.

---

## Если не работает

| Что видите | Что делать |
|---|---|
| `command not found: claude` | Новый терминал или блок с PATH выше |
| `ask-pbi` не Connected | Проверьте ключ, попросите новый у Михаила |
| Нет отчёта в app.powerbi.com | Это отдельно от Claude — доступ у админа |
| Нужна новая цифра в отчёте | Напишите Михаилу — добавим в каталог |
